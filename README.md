# Todo App – React & Tailwind CSS

Bu proje, Web Geliştirme (JavaScript) eğitimi kapsamında geliştirilmiş bir frontend uygulamasıdır.  

---

## 🚀 Kullanılan Teknolojiler

- **ReactJS** – Modern JavaScript kütüphanesi
- **Vite** – Hızlı geliştirme ve build aracı
- **Tailwind CSS** – Utility-first CSS framework
- **LocalStorage** – Tarayıcı üzerinde veri saklama
- **Git & GitHub** – Versiyon kontrolü
- **Netlify** – Yayına alma

---

## 📁 Proje Klasör Yapısı

```
src/
├── components/            # Tekrar kullanılabilir arayüz bileşenleri
│    └── TodoItem.jsx      # Tek bir todo öğesini gösteren ve düzenleyen bileşen
│
├── pages/                 # Sayfa seviyesindeki bileşenler
│    └── Home.jsx          # Ana todo sayfası (listeleme, ekleme, güncelleme, silme)
│
├── interfaces/            # Veri modeli ve yardımcı fonksiyonlar
│    └── todo.js           # Todo nesnesi oluşturma yardımcı fonksiyon
│
├── App.jsx                # Uygulamanın kök bileşeni
├── main.jsx               # React uygulamasının giriş noktası
├── index.css              # Genel stiller ve Tailwind başlangıcı
```

---

## ✨ Uygulama Özellikleri

Todo App uygulaması, eğitimde işlenen örnek proje baz alınarak geliştirilmiştir ve aşağıdaki işlemleri içermektedir:

- ➕ **Todo Ekleme**
- 📋 **Todo Listeleme**
- ✏️ **Todo Güncelleme**
- 🗑️ **Todo Silme**
- 💾 **LocalStorage desteği**
  - Sayfa yenilendiğinde veriler kaybolmaz
